# Purpose of the project

Project made to warm up my self with Elixir language, by learning the first things, like file system manipulation.

## Things I learned

File system manipulation; using modules, such as 'Enum', 'System', 'Path', 'File'; recursion instead
of loopings; elixir syntax. I also divided the responsibilities by modules, like: validation (since it's a cli program,
I had to take care of input validation), error messaging and the actual file organization logic, all separated in modules
by responsibility.
